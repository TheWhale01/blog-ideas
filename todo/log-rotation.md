# Log Rotation

When `log.md` exceeds **500 lines**, rename it to `log-YYYY-MM-DD.md`, start fresh. Prior entries are preserved in the original `log.md`; the new file holds today's update only.

## History
- Triggered 2026-11-11: `log.md` reached ~751 lines (>500).
- New file created: `log-2026-11-11.md`.
- Old `log.md` retained as historical archive.
